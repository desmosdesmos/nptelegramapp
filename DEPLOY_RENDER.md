# Деплой на Render.com (Бесплатно)

## Шаг 1: Зарегистрируйтесь на Render

Перейдите на https://render.com и создайте аккаунт (через GitHub, GitLab или email).

## Шаг 2: Запушьте код на GitHub

Если ещё не запушен:

```bash
git add .
git commit -m "Добавлена конфигурация для Render"
git push origin main
```

## Шаг 3: Создайте Static Site на Render

1. Войдите в https://dashboard.render.com
2. Нажмите **"New +"** → **"Static Site"**
3. Подключите ваш GitHub репозиторий
4. Заполните настройки:

   | Поле | Значение |
   |------|----------|
   | **Name** | `np-auto-detail-miniapp` (или любое другое) |
   | **Branch** | `main` (или `master`) |
   | **Root Directory** | оставьте пустым |
   | **Build Command** | `npm install && npm run build` |
   | **Publish Directory** | `dist` |

5. Нажмите **"Create Static Site"**

## Шаг 4: Готово!

Через 2-5 минут сайт будет доступен по URL вида:
```
https://np-auto-detail-miniapp.onrender.com
```

## Обновление сайта

При каждом `git push` в ветку `main` Render автоматически пересоберёт и обновит сайт.

## Важные замечания

- ✅ **Бесплатно** — нет платы за статические сайты
- ✅ **HTTPS** — автоматически
- ✅ **Авто-деплой** — при пуше в GitHub
- ⚠️ **Сон** — на бесплатном тарифе сайт "засыпает" после 15 мин простоя (первый запрос после простоя может занять 30-50 сек)
