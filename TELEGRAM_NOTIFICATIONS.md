# Настройка уведомлений Telegram

## Как настроить уведомления о заходе пользователей в бота

### Шаг 1: Создайте Telegram бота

1. Откройте Telegram и найдите бота **@BotFather**
2. Отправьте команду `/newbot`
3. Введите имя для вашего бота (например, `NP Notification Bot`)
4. Введите username для бота (должен заканчиваться на `bot`, например, `np_notification_bot`)
5. BotFather выдаст вам **API токен** (выглядит как `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz`)

### Шаг 2: Узнайте свой User ID

Ваш User ID уже указан: **478799066**

Если нужно узнать ID другого пользователя:
1. Добавьте бота **@userinfobot** в контакты
2. Отправьте ему любое сообщение
3. Он пришлет ваш User ID

### Шаг 3: Настройте переменные окружения

#### Для локальной разработки (.env файл):

```env
TELEGRAM_BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
TELEGRAM_ADMIN_ID=478799066
```

#### Для продакшена (.env.production файл):

```env
TELEGRAM_BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
TELEGRAM_ADMIN_ID=478799066
```

### Шаг 4: Активируйте бота

1. Найдите созданного бота в Telegram по username
2. Нажмите **Start** или отправьте команду `/start`

### Шаг 5: Запустите сервер

```bash
cd server
npm install
npm start
```

### Шаг 6: Проверьте работу

1. Откройте ваше приложение в Telegram
2. Вы должны получить уведомление в Telegram с информацией:
   - ID пользователя
   - Имя и фамилия
   - Username
   - Язык
   - Premium статус
   - Время захода (в часовом поясе Москвы)

## Дополнительные возможности

### Уведомление о действиях пользователя

Вы также можете отправлять уведомления о действиях пользователя через endpoint:

```
POST /api/notify/action
```

Пример запроса:

```json
{
  "userId": 123456789,
  "username": "ivanov",
  "firstName": "Иван",
  "action": "Запись на услугу",
  "details": "Химчистка салона",
  "timestamp": "2026-03-29T12:30:00Z"
}
```

## Решение проблем

### Уведомления не приходят

1. Проверьте, что бот активирован (отправьте ему `/start`)
2. Проверьте правильность токена в `.env`
3. Проверьте, что сервер запущен
4. Проверьте логи сервера на наличие ошибок

### Ошибка "Telegram bot not configured"

Убедитесь, что переменные окружения `TELEGRAM_BOT_TOKEN` и `TELEGRAM_ADMIN_ID` установлены в `.env` файле сервера.

### Ошибка CORS

Если получаете ошибку CORS, убедитесь, что `CORS_ORIGIN` настроен правильно в `server.js`.
